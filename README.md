# 🇫🇷 Dire la nationalité (FLE A1)

A beginner-friendly **French as a Foreign Language (FLE A1)** lesson designed to help learners **ask and state nationalities**, use **negative sentences with the verb *être***, and correctly **agree nationality adjectives** in French.

---

## 📖 Overview

This repository contains teaching materials for introducing and discussing nationality in French. It includes grammar explanations, sentence structures, adjective agreement rules, examples, and classroom activities suitable for beginner learners. :contentReference[oaicite:0]{index=0}

---

## 🎯 Learning Objectives

By the end of this lesson, learners will be able to:

- Ask someone's nationality.
- State their own nationality.
- Describe another person's nationality.
- Form negative sentences using **ne...pas**.
- Apply gender and number agreement to nationality adjectives.
- Complete written and oral activities using the target language. :contentReference[oaicite:1]{index=1}

---

## 📚 Lesson Content

### 🗣️ Asking about Nationality

- Quelle est ta nationalité ?
- Quelle est votre nationalité ?
- Il est de quelle nationalité ?
- Elle est de quelle nationalité ?

### 💬 Saying Your Nationality

Structure:

```text
Je suis + nationalité
```

Examples:

```text
Je suis nigérian.
Je suis nigériane.
Je suis gabonais.
Je suis gabonaise.
Je suis sénégalais.
Je suis sénégalaise.
```

---

## ❌ Negative Form

The lesson introduces the French negation:

```text
Sujet + ne / n' + verbe + pas
```

Examples:

```text
Je ne suis pas nigériane.
Madame Lloyd n'est pas nigériane.
```

> **Note:** *n'* is used before a vowel (a, e, i, o, u, y). :contentReference[oaicite:2]{index=2}

## 📖 Grammar Focus

### Verb **Être** (Negative Form)

| Subject | Negative Form |
|---------|---------------|
| Je | ne suis pas |
| Tu | n'es pas |
| Il / Elle | n'est pas |
| Nous | ne sommes pas |
| Vous | n'êtes pas |
| Ils / Elles | ne sont pas |

## ✍️ Nationality Adjective Agreement

The lesson explains how nationality adjectives agree with gender and number.

### Examples

| Masculine | Feminine |
|-----------|----------|
| français | française |
| nigérian | nigériane |
| canadien | canadienne |

It also introduces common adjective endings, including:

- **-ais / -aise**
- **-ien / -ienne**
- **-an, -en, -ain → -ane, -enne, -aine**

with examples such as:

- français / française
- japonais / japonaise
- canadien / canadienne
- italien / italienne
- nigérian / nigériane
- marocain / marocaine
- australien / australienne
- brésilien / brésilienne :contentReference[oaicite:3]{index=3}
